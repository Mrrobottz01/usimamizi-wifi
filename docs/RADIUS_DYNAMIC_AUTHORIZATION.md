# RADIUS Dynamic Authorization (RFC 3576 / RFC 5176) & Disconnect Management

Technical architecture of RADIUS dynamic authorization and real-time session termination in **Usimamizi Wi-Fi** (Phase 5).

---

## 1. Overview & Protocol Specification

RFC 3576 / RFC 5176 defines dynamic authorization extensions to RADIUS, enabling a centralized AAA controller to send server-initiated packets to a Network Access Server (NAS):

- **Disconnect-Request (Code 40):** Instructs the NAS router (MikroTik HotSpot) to terminate an active user session immediately.
- **Disconnect-ACK (Code 41):** Sent by the NAS to confirm session termination.
- **Disconnect-NAK (Code 42):** Sent by the NAS if session could not be found or request was rejected.
- **Port:** UDP 3799 (standard dynamic authorization port).

```text
Usimamizi AAA (Django / SessionControlService)
        │
        ▼ UDP 3799 (Disconnect-Request, Code 40)
MikroTik HotSpot NAS (192.168.1.109 / 192.168.88.1)
        │
        ├─► Physical HotSpot Session Dropped
        │
        ▼ UDP 3799 (Disconnect-ACK, Code 41)
Usimamizi Session Controller (SessionDisconnectRequest: ACKNOWLEDGED)
        │
        ▼ Accounting Stop (Acct-Status-Type = Stop)
HotspotSession (status: STOPPED)
```

## 2. MikroTik RouterOS 6 Dynamic Authorization Configuration

To accept Disconnect-Requests from the trusted AAA controller (`192.168.1.163`):

```routeros
# Enable incoming RADIUS dynamic authorization on port 3799
/radius incoming set accept=yes port=3799

# Allow UDP 3799 from trusted AAA server only in Firewall
/ip firewall filter add chain=input action=accept protocol=udp dst-port=3799 src-address=192.168.1.163 comment="Allow RADIUS CoA/Disconnect from Usimamizi AAA"
```

## 3. Session Identification & Disconnect Payload

Disconnect-Requests generated by [`apps/hotspot_sessions/services/session_control.py`](file:///c:/Users/fsociety/Documents/Usimamizi-wifi/backend/apps/hotspot_sessions/services/session_control.py) include:
1. `User-Name` (Code 1): Client voucher code / account username.
2. `Acct-Session-Id` (Code 44): Unique accounting session identifier emitted during RADIUS Start/Interim.
3. `Calling-Station-Id` (Code 31): Canonical normalized client MAC address (`AA:BB:CC:DD:EE:FF`).
4. `NAS-IP-Address` (Code 4): IP address of the targeted NAS router.
5. `Framed-IP-Address` (Code 8): Client IP assigned on HotSpot network.
