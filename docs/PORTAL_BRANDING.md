# Captive Portal Branding & Theming Tokens

Guide for customizing tenant-specific captive portal appearance and branding in **Usimamizi Wi-Fi** (Phase 6).

---

## 1. Supported Branding Tokens

| Token Field | Type | Description |
| :--- | :--- | :--- |
| `brand_name` | String | Customer-facing business display name (e.g. *Hotel Kariakoo Guest Wi-Fi*). |
| `headline` | String | Catchy welcome headline. |
| `welcome_text` | Text | Short customer greeting or Wi-Fi instructions. |
| `primary_color` | Hex Color | Accent color applied to buttons, badges, and focus rings. |
| `logo_url` | URL | High-resolution brand logo displayed on top of the portal. |
| `support_phone` | Phone String | Direct phone number for guest support / voucher sales. |
| `default_language` | `EN` \| `SW` | Default portal interface language (English or Kiswahili). |

---

## 2. Admin Live Simulator

Tenant administrators can preview branding customizations directly inside an interactive smartphone simulator on `/settings/hotspot`.
